# Crag Details

This table describes the information that a crag entry can contain in the Family Crag app. “Mandatory” means the information is required to create a crag entry. Optional photo details are not required unless a photo is added.

| Section | Criterion | Type | Mandatory? | Status | Notes |
|---|---|---|---|---|---|
| Basic information | Crag name | String | Yes | Implemented | |
| Basic information | Area name | String | Yes | Implemented | Select an existing area or add a new one. |
| Photos | Photo uploads | String (image file; multiple photos) | No | Implemented | Photos can be added to a crag. |
| Photos | Photo category | String (choice) | No | Partially implemented | Crag, base area, approach, parking, and other are available. There is no dedicated category for the surrounding terrain. |
| Family suitability | Overall family rating | Number (1–5) | No | Implemented | The app currently has one overall rating, not separate ratings by age group. |
| Family suitability | Rating for babies (0–1 year) | Number (1–5) | No | Not implemented | |
| Family suitability | Rating for children (1–4 years) | Number (1–5) | No | Not implemented | |
| Family suitability | Rating for children aged 5 and older | Number (1–5) | No | Not implemented | |
| Approach | Walking time to the crag | Number (minutes) | No | Implemented | |
| Approach | Suitable for a stroller | String (Yes, Partially, No, or Unknown) | No | Implemented | |
| Approach | Fall hazard | Boolean | No | Not implemented | Indicates whether there is a risk of falling on the approach. |
| Base of the crag | Rockfall hazard | Boolean | No | Not implemented | |
| Base of the crag | Fall hazard | Boolean | No | Not implemented | |
| Base of the crag | Suitable for a stroller | Boolean | No | Not implemented | |
| Crag | Orientation | String (compass direction) | No | Implemented | North, North-East, East, South-East, South, South-West, West, or North-West. |
| Crag | Space or opportunity for a swing | Boolean | No | Not implemented | |
| Crag | Location | String (map link or location details) | No | Not implemented | |
| Parking | Location | String (map link or location details) | No | Not implemented | |
| Other information | Family notes | String (free text) | No | Implemented | Use this field for additional information relevant to families. |
